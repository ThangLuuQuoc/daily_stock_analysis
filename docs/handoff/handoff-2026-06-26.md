Nguồn dữ liệu: OpenStock (Bun/Elysia) tại `F:\2026\2027\openstockV1`, base `http://localhost:3000/api/v1` — **không sửa OpenStock**, chỉ dùng endpoint public.

## Trạng thái: hoạt động được, ưu tiên Tiếng Việt

Phân tích cổ phiếu VN + Market Review đều ra **tiếng Việt** end-to-end. Giao diện mặc định Tiếng Việt (switch chỉ EN/VI).

## Khởi động (mỗi phiên — tiến trình nền bị teardown khi phiên kết thúc)
| Service | Port | Lệnh |
|---|---|---|
| OpenStock (data VN) | 3000 | user tự chạy (`cd openstockV1 && bun run dev`); cần Postgres :5433 + Redis :6379 |
| DSA backend (FastAPI) | 8000 | `OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 PYTHONIOENCODING=utf-8 python -m uvicorn server:app --host 127.0.0.1 --port 8000` |
| dsa-web (Vite) | 5174 | `cd apps/dsa-web && bunx vite --port 5174 --host 127.0.0.1` (5173 = OpenStock frontend) |

Môi trường: Python 3.14 (numpy cần `OPENBLAS_NUM_THREADS=1`), console cp1252 (`PYTHONIOENCODING=utf-8`), bun cần `bunfig.toml` trỏ corp CA. China data libs KHÔNG cài (defensive import bỏ qua).
